---
title: When to use
---

## Good fit when

- You want people to learn about the Tallmaker extensions in an app without leaving Qlik Sense.
- You want a help sheet dedicated to one product: choose it in **Product**.
- You need help that matches the installed extension version.
- You want to search the docs of several installed Tallmaker products in one place.

## Not a good fit when

- You want to display or analyse app data. Use a native Qlik table, bar chart or other chart suited to your question.
- You want to write your own app instructions. Use a native Qlik text object for those notes.
- You need help inside an embedded page or mashup. Read the product documentation on the Tallmaker website instead.
- You need older-version docs or a printable manual. The reader has no version archive, print or PDF view; use documentation supplied separately for that version instead.

## What it needs

The reader needs no dimensions, measures or app data. Use it on a sheet in the Qlik Sense client on Qlik Cloud. A Tallmaker product appears when its installed version includes docs; installing the reader does not add docs to older versions of other extensions.
