## Installed version only

The reader shows the docs that ship with the installed version. It keeps no archive of older versions. After an extension is updated, reload the app to see its new docs.

## Products without docs

A product shows in the index only when its installed version ships docs. Older versions of an extension have no docs yet.

## Where the reader works

The reader works in the Qlik Sense client on Qlik Cloud. In an embedded page or a mashup the reader cannot read the docs of other extensions, so it shows "Docs are unavailable here".

## Safety

The reader reads the docs as data. It checks each file before it shows it, and never runs code from a docs file. The reader is free and reads no licence.
