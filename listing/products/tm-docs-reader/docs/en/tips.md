## I cannot find an installed product

The reader lists installed Tallmaker products whose installed versions include docs. An older version may not include them yet. Ask your Qlik administrator whether a version with docs is available, then reload the app after an update.

If the reader shows only one product, check **Docs reader → Product** in edit mode. Choose **All installed products** to browse the others.

## Search does not find the topic I need

Try a shorter word or the name of a setting. Search covers the installed products' docs, in English. If **Product** is set to one product, search covers only that product; choose **All installed products** to search more widely.

## The reader opens the wrong page

Check **Start page (product/page)** under **Docs reader**. For this guide's settings page, use `tm-docs-reader/settings`. If a page no longer exists, the reader opens the product's first page. Make sure the start page belongs to the product selected in **Product**, or clear the field to use the usual opening view.

## I see “Docs are unavailable here”

Open the app directly in the Qlik Sense client on Qlik Cloud. Embedded pages and mashups cannot read the other extensions' docs. Use the product documentation on the Tallmaker website when reading outside the client.

## The docs look different after an update

The docs follow the installed extension version. Reload the app after an extension update to see its new docs. The reader keeps no archive of previous versions.

## I need another language or a PDF

The reader currently offers English only. It has no print, PDF or story mode. Read the pages in the reader, or use documentation supplied separately for your product if you need another format.
